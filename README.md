# Anta Seck

### Développeuse Web & Mobile

Je conçois et développe des applications web modernes en mettant l'accent sur la simplicité, la qualité du code et l'expérience utilisateur.

Actuellement en développement de mes compétences en développement web et mobile, je travaille principalement avec React, Django et les API REST.

## À propos

Je m'intéresse particulièrement à la conception d'applications utiles, structurées et adaptées aux besoins réels des utilisateurs.

Mon approche repose sur trois principes :

* écrire un code clair et maintenable ;
* concevoir des interfaces simples et intuitives ;
* comprendre le besoin métier avant de développer la solution.
